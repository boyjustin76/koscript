# `docx` — 워드 문서 수술 키트

**남이 만든 `.docx` 양식을 깨뜨리지 않고 고치고, 사람이 남긴 검토 표시를 읽고, 새 문서를
그 양식 그대로 짓는다.**

| 쓸 때 | 모듈 |
|---|---|
| 문서를 풀고 다시 묶는다 | `pack` |
| 글·표 칸·**취소선/밑줄/색 표시**를 읽는다 | `read` |
| 두 판을 문단 단위로 **전수 대조**한다 | `diff` |
| 고친다 — **몇 군데 고쳤는지 세면서** | `edit` |
| 새 문서를 OOXML 로 짓는다 | `build` |
| PDF·쪽 그림으로 **눈으로 본다** | `render` |

## 들어가는 것 / 나오는 것

- 들어가는 것 — `.docx` 파일 경로, 또는 푼 폴더
- 나오는 것 — 문자열(본문 XML), 줄 목록, 새 `.docx`, 쪽 그림

**바깥 자료는 필요 없다.** `render` 만 LibreOffice 와 poppler 가 깔려 있어야 한다(아래).

## 한 줄 예시

```python
from koscript.docx import pack, read, edit

푼곳 = pack.풀기('양식.docx', '작업')
xml = pack.본문읽기(푼곳)

# 사람이 남긴 검토 표시 읽기 — 취소선은 지울 것, 밑줄은 고친 것
for 번호, 글 in read.표시읽기(xml):
    print(번호, 글)        # 12 그래서 다음에는 [-무너지는 날도 있죠.-][_무너지죠._]

# 정확히 한 군데만 고친다. 두 군데면 멈춘다
xml = edit.한번만(xml, '무너지는 날도 있죠.', '무너지죠.')
edit.지킴(xml, 없어야=['무너지는 날도'], 있어야=['무너지죠'])

pack.본문쓰기(푼곳, xml)
pack.묶기(푼곳, '고친것.docx')
```

사람이 손본 판이 왔을 때는 **표시만 보지 말고** 전수로 맞댄다:

```python
from koscript.docx import diff
for 줄 in diff.대조(내xml, 받은xml, '내판', '받은판', 취소선뺌=True):
    print(줄)
```

## 넘어진 자리 — 먼저 읽으면 하루 아낀다

1. **`[Content_Types].xml` 은 zip 맨 앞**이어야 한다. 이름순으로 묶으면 워드가 안 연다.
   `pack.묶기` 가 강제한다.
2. **`<w:pPr>`·`<w:rPr>` 안의 원소 차례는 스키마가 못 박는다.** 차례가 틀리면
   `Element 'spacing': This element is not expected` 로 거부당한다. `build` 가 강제한다.
3. **워드는 한 문장을 여러 런으로 쪼갠다.** 눈에 보이는 문구가 XML 에 이어진 문자열로
   없을 수 있다. 못 짚으면 `edit.문단바꾸기` 로 번호를 짚는다.
4. **`<w:t[^>]*>` 로 글을 뽑지 마라.** `<w:tbl>`·`<w:tc>` 까지 걸려서 XML 토막이
   본문으로 섞여 나온다. `read` 는 `<w:t(?: [^>]*)?>` 로 잡는다.
5. **지은 문서는 반드시 렌더해서 눈으로 본다.** 마크다운 `**` 가 그대로 찍히는 사고를
   세 번 냈다.
6. 문자열로 바꿀 때는 **몇 번 찾았는지 센다**(`edit.한번만`). 엉뚱한 데가 같이 바뀐다.

## `render` 가 필요로 하는 것

- **LibreOffice** — `soffice` 가 PATH 에 있으면 그대로 쓴다. 없으면 흔한 설치 자리를 찾는다.
  못 찾으면 환경변수 `SOFFICE` 에 실행 파일 경로를 준다.
- **poppler** (`pdftoppm` 등) — 마찬가지. 환경변수는 `POPPLER_BIN` (bin 폴더 경로).

윈도우에서는 LibreOffice 를 PowerShell `Start-Process -Wait` 로 띄운다. 그냥 부르면
조용히 끝나고 PDF 가 안 나온다.
